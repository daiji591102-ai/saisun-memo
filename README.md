# 採寸メモ

衣類の採寸を**音声で**記録して、フリマ出品の説明文用にコピーできる単体Webアプリ。

- スマホのホーム画面に追加すると、アプリとして起動します（PWA）
- 一度開けば**オフラインでも動きます**
- 入力した採寸は端末内に自動保存されます（リロードしても消えません）
- 「書出/読込」で JSON バックアップができます

公開URL: https://daiji591102-ai.github.io/saisun-memo/

## 使い方
1. 商品名を入力（マイクボタンで音声入力も可）
2. 「録音」を押して「肩幅40 身幅50 着丈60」のように話す
3. 「表に追加」で一覧へ。セルをタップすれば手修正できます
4. 「テキストコピー」で出品用の説明文形式にしてコピー

## 中身
- `docs/index.html` … アプリ本体（単体HTML・外部依存なし）
- `docs/manifest.json` / `docs/sw.js` … ホーム画面アプリ化とオフライン動作
- 記録したデータは端末内（localStorage）にのみ保存され、どこにも送信されません
